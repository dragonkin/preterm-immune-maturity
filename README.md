# 早产儿免疫成熟度（免疫年龄）研究

> 基于公开单细胞转录组数据，构建早产儿免疫成熟度/免疫年龄评分，并与新生儿并发症（败血症、NEC、BPD）关联。
>
> *Preterm immune maturity (immune age) research — derived from public single-cell transcriptomic datasets.*

---

## 项目简介

早产儿免疫系统发育不全，与败血症、坏死性小肠结肠炎（NEC）、支气管肺发育不良（BPD）等并发症密切相关。本项目**首次将"免疫年龄 / 免疫成熟度"概念由成人（肿瘤、免疫衰老）系统迁移到早产儿免疫评估**，并采用**完全公开数据**（GEO 单细胞数据集）做二次分析与建模，**无需自建病例队列**即可开展，尤其适合基层/无充足本院数据的儿科研究团队。

## 已核验的数据基础

本课题所需数据已经过真实检索与下载实测（2026-11，NCBI GEO E-utilities）：

| 数据集 | 内容 | 用途 |
|---|---|---|
| GSE271413 | 极早产儿出生后 2 个月循环免疫单细胞图谱（足月 vs 早产 vs 成人，含宫内炎症暴露） | 主训练/验证 |
| GSE326288 | 早产 vs 足月 PBMC（含成人对照） | 跨队列验证 |
| GSE253963 / GSE236099 | 新生儿 MDSC；极早产败血症 scRNA+CITE-seq | 疾病维度 |
| GSE302276 / GSE157007 | 脐血→成年的成熟梯度 | 成熟度连续化 |

> 已实测：GSE271413 文件可正常下载（1.4 GB RAW.tar），字节数与 GEO 清单一致，标准 10x 三件套格式。

## 方法路线（计划）

1. 多队列整合（Harmony / scVI 去批次）→ 细胞注释（SingleR / CellTypist）
2. 免疫成熟度基因签名 → 逐样本评分（AUCell / UCell / AddModuleScore）
3. 拟时序建模早产儿免疫成熟滞后（Monocle3 / scVelo）
4. 与败血症 / 宫内炎症结局关联，验证分层价值
