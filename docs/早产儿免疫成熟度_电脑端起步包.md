# 电脑端起步包：装环境 + 下载 GSE271413 + 读取数据

> 目标：在你的电脑上装好环境，把 GSE271413（早产儿免疫图谱，1.4G 原始数据）下载下来并读成可分析的单细胞对象。
> 耗时参考：装环境 1-2 小时；下载 1.4G 视网速而定；读取 1 小时以内。

---

## 0. 硬件与系统
- 内存：**≥16G 较稳**；8G 也能读但后续跑整合会卡。
- 系统：Windows / Mac / Linux 均可。下面以 R 路线为主，兼顾 Windows 特例。

---

## 1. 安装 R + RStudio（推荐路线，约 30-60 分钟）

### 第 1 步 装 R
- 官网下载对应系统版本：https://cran.r-project.org/
  - Windows：点 "Download R for Windows" → base → 安装
  - Mac：点 "Download R for macOS"
- 装完打开，能敲入 `1+1` 回车返回 `2` 即成功。

### 第 2 步 装 RStudio（免费桌面版）
- 下载：https://posit.co/download/rstudio-desktop/
- 装完打开 RStudio，界面有 4 个窗格，**左下是控制台(Console)**，代码都在那里跑。

### 第 3 步 在 R 里装 Seurat（单细胞核心包）
在 RStudio 左下控制台逐行粘贴运行（跑几分钟属正常）：
```r
install.packages("Seurat")
library(Seurat)
```
若提示缺依赖，继续 `install.packages(c("SeuratData","Signac"))` 之类，按报错装即可。
> 报错就整段复制发我，我帮你定位。

（可选 Python 路线，二选一即可，不建议同时学：装 Anaconda → `pip install scanpy anndata`。）

---

## 2. 下载 GSE271413（1.4G）
任选一种：
- **浏览器直下（最省事）**：打开
  `https://ftp.ncbi.nlm.nih.gov/geo/series/GSE271nnn/GSE271413/suppl/GSE271413_RAW.tar`
  直接保存。务必备份（以后要反复用）。
- **命令行**（RStudio 右下角 Terminal / CMD / 终端）：
  - Windows：`curl.exe -L -o GSE271413_RAW.tar "https://ftp.ncbi.nlm.nih.gov/geo/series/GSE271nnn/GSE271413/suppl/GSE271413_RAW.tar"`
  - Mac/Linux：`curl -L -o GSE271413_RAW.tar "https://ftp.ncbi.nlm.nih.gov/geo/series/GSE271nnn/GSE271413/suppl/GSE271413_RAW.tar"`

### 解压
- Windows：右键 → 用 7-Zip 打开解压（先装 7-Zip）。
- Mac/Linux：`tar -xvf GSE271413_RAW.tar`
- 解压后每个样本一个小文件夹，含三件套：`*_barcodes.tsv.gz`、`*_features.tsv.gz`、`*_matrix.mtx.gz`（标准 10x 格式）。

---

## 3. 读取成单细胞对象（R 代码）
把 `data.dir` 换成你解压后任意一个样本文件夹的路径：
```r
library(Seurat)
data <- Read10X(data.dir = "C:/你的路径/GSM8376457_1317_1")
obj <- CreateSeuratObject(counts = data, project = "GSE271413")
obj
# 若上方代码一行都不报错，你会看到几列几行的矩阵信息，即成功
```
成功标志：控制台打印如 `4485 features across 1991 samples` 之类（数字只是示例）。
再跑一句能出细胞质量统计：
```r
obj[["percent.mt"]] <- PercentageFeatureSet(obj, pattern = "^MT-")
VlnPlot(obj, features = c("nFeature_RNA", "nCount_RNA", "percent.mt"), ncol = 3)
```

---

## 4. 读取后 / 常见坑
- **分组信息**：样本命名里的 `TCB`=足月脐血、`PTCB`=早产脐血、`adult`=成人、`_1/3/5`=出生后时间点（第1/3/5天）。正式做之前务必到原论文/补充材料核对这些分组映射。
- **内存不足**：先只读 1-2 个样本，别一上来全读 30 多个。
- **报错处理**：把红色报错整段发我，比你自己搜快得多。
