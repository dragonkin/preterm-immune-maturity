## 推荐从这 3 个里选 1 个先试（由易到难）

### 方案甲：GPT-Researcher（最快，网页就能试）
- 入口：打开 https://app.gptr.dev/ （网页版 live demo，浏览器直接用）
- 用法：直接输入你的一句研究问题，例如：
  > "A systematic review of immune maturation / immune age in preterm and term neonates using single-cell transcriptomics: current evidence, methods, and gaps."
- 它会自动检索 → 生成带行内引用的研究/综述报告。走一遍就懂 AI 自动写综述是啥感觉。

### 方案乙：ASReview（做规范筛选，最被综述界认可）
- 入口：电脑装好后在本机打开网页界面（无 key、免费、可离线）：
  - Windows 装 Python 后用命令 `pip install asreview` 然后 `asreview lab`
  - 或直接下载 ASReview 桌面/网络版安装包（见 asreview.nl）
- 用法：把你在 PubMed 导出的文献（RIS/.nbib）导入，AI 帮你按"相关/不相关"排序和筛选，符合 PRISMA。
- 适合当你决定"走规范系统综述投稿"时用。

### 方案丙：STORM（自动生成百科式长文综述）
- 入口：斯坦福在线 demo（storm.genie.stanford.edu）或本地/Colab 版
  - GitHub: https://github.com/stanford-oval/storm （README 里有 Colab 一键开跑）
- 用法：输入题目，自动产出带引用的长篇综述。
- 备注：它写的是 survey（综述式长文）不是严格系统综述，且该仓库近期更新少，适合"快速出草稿"。

```
重点：
1) 围产免疫发育背景；2) 早产儿免疫不成熟与败血症/NEC/BPD 的关联；

5) 现有证据缺口与我建议的研究方向。
请在正文后附引用列表，并**只引用真实存在的文献**。
```
