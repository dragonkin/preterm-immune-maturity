# 早产儿免疫成熟度评分 — 分析 Pipeline 草稿（7 步）

> 作用：把 GEO 公开数据从"下载"一路跑到"能写进论文的图/表"。下面每一步给了用的方法与产物。
> 环境前置：需要 R（Seurat）或 Python（scanpy/anndata）+ 一个能跑得动单细胞计算的电脑/服务器。

## 第 1 步 · 下载原始数据
- 抓取 GSE271413、GSE326288、GSE302276、GSE157007、GSE236099、GSE253963 等（见数据可及性报告）。
- 取过滤后的计数矩阵（MTX/TSV）+ 样本元数据（哪管是早产/足月/成人、哪天采血、有无败血症/炎症）。
- 产物：每套数据一个 `h5ad` 或 `Seurat对象`。
- ⚠️ 关键：先核对每套的样本分组表（有些表型在原论文补充材料），分组错了一切白搭。

## 第 2 步 · 质控与整合
- 每套独立质控：过滤低质量细胞（少基因/高线粒体，通常 mitochondrial % 阈值）、去 doublet（Scrublet / DoubletFinder）。
- 多套数据合并后用 **Harmony 或 scVI 批次校正**，消除"不同批次来源"的差异（否则会把"批次"误当成"早产效应"）。
- 产物：整合好的、打上批次/早产/足月/年龄标签的细胞×基因矩阵。

## 第 3 步 · 细胞类型注释
- 用 SingleR / CellTypist + 已知免疫基因做自动注释，再人工校准成免疫共识分群（T、B、NK、髓系/单核、中性粒、DC 等）。
- 产物：每个细胞一个"免疫细胞类型"标签；后续按类型分别分析。

## 第 4 步 · 免疫成熟度评分（核心）
- 定义"免疫成熟"基因签名：由 **足月 vs 早产的差异基因** ∩ **权威参考免疫发育谱** 取交集。
- 用 AUCell / UCell / AddModuleScore 给每个细胞、每个样本打一个"成熟度分数"。
- 产物：每例新生儿一个"免疫成熟度分数"。

## 第 5 步 · 差异与成熟轨迹
- 早产 vs 足月、同胎龄纵向（0–60 天）的差异细胞类型/通路。
- Monocle3 / scVelo 拟时序，看免疫细胞随出生后天数/胎龄的"成熟轨迹"，量化"早产儿的成熟滞后"。
- 产物：UMAP 图、轨迹图、差异通路气泡图。

## 第 6 步 · 结局关联（临床意义）
- 把"免疫成熟度分数"与疾病表型关联：败血症 / 宫内炎症（绒毛膜羊膜炎）分组做 ROC、回归，看低成熟是否预示感染/炎症。
- 产物：ROC 曲线、多组箱线图、风险分层表。

## 第 7 步 · 可视化与成文
- 汇总所有图（UMAP、轨迹、评分箱线、ROC、热图）→ 整理成论文图表，写入结果/讨论。

## "可直接跑"的真实边界（诚实说明）
- "直接跑"= 我给你**每一步的脚本/命令、参数和阈值**，你照抄在自己的 R/Python 环境里运行就能出结果，**不用自己设计方法**。
- 但需要你：有一台能跑的电脑（或租云服务器），并且**会最基本地运行脚本**（RStudio 里点 Run，或命令行 source）。如果完全没用过生信，我也可以把步骤写成**图形界面（RStudio）可操作版**或分阶段教学。
- 单细胞数据处理较重（几个数据集合并后可能几十万–百万细胞），普通笔记本可能吃力，通常建议 ≥16G 内存或租个小服务器。
